# What-If Short Script

Write an original, fast-paced, ~60-second animated explainer script answering the user's "what if" question. Match the genre of viral 3D-animation explainer shorts, but write entirely original narration. Do not copy, imitate, or name any real creator's catchphrases or branding.

## Output format

1. **Title**: 3–7 words, curiosity-driven (e.g. "What If Earth Spun Backwards?").
2. **Hook (0–3s)**: One line that makes the viewer stay. Start mid-action or with a surprising claim.
3. **Scenes (4–7 beats)**: For each beat give:
   - `[VISUAL]`: what the 3D animation shows (camera move, object, scale shift).
   - `VO:` 1–2 short narration sentences, under 20 words each.
   - Each beat escalates: personal scale → city → planet → long-term consequences.
4. **Twist / payoff (last 5s)**: An unexpected final fact or a reversal that reframes everything.
5. **Fact check**: 2–4 bullets noting which claims are well established and which are speculative, with the source type (e.g. climate model study, physics principle).

## Style rules

- Second person ("you wake up and…") where it fits.
- Short, punchy sentences. No filler, no "in this video".
- Every claim must be scientifically grounded. Mark speculation as such in the fact check, not in the narration.
- Total narration: 130–170 words (≈60 seconds spoken).
- Where it fits naturally, include one Singapore or Southeast Asia angle.
- Avoid clichéd AI words: delve, testament, beacon, hurdle, paramount, leverage, multifaceted, underscore, pivot, tapestry.

## End

After the script, offer one follow-up: a longer 3-minute version, a thumbnail concept, or on-screen caption text.
